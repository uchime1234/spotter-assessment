# OpenStreetMap data attribution

The eleven state JSON files are a normalized spatial database of OpenStreetMap fuel features, locality points and interstate exit references. © OpenStreetMap contributors. Distributed under the Open Database License 1.0. See the enclosed license text and https://www.openstreetmap.org/copyright. Preserve this notice and apply the ODbL requirements when redistributing or publicly using the database or an adaptation.

Source extracts: Geofabrik regional US PBFs, https://download.geofabrik.de/north-america/us.html. Each JSON file records the SHA-256 of its source PBF. The kit includes no Spotter price file, OPIS crosswalk, generated catalog, operator feed, or Census address submissions.
